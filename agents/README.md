# Game Design Agents

Specialized agent definitions for game design workflows. Each agent focuses on a specific aspect of game development.

## Agents

| Agent | File | Focus |
|-------|------|-------|
| Level Designer | [level-designer.md](./level-designer.md) | Level layouts, pacing, enemy/item placement |
| Game Mechanic Designer | [game-mechanic-designer.md](./game-mechanic-designer.md) | Core mechanics, player abilities, systems |
| Narrative Designer | [narrative-designer.md](./narrative-designer.md) | Story, characters, dialogue, world-building |
| Balance Designer | [balance-designer.md](./balance-designer.md) | Difficulty curves, stats, economy, tuning |
| UX/UI Designer | [ux-ui-designer.md](./ux-ui-designer.md) | HUD, menus, tutorials, visual feedback |

## How to Use

1. Pick the agent that matches your current task
2. Follow the workflow outlined in the agent file
3. Use the output format as a template for your deliverables
4. Reference best practices when making design decisions

## Workflow Example

```
GDD Draft → Mechanic Designer → Level Designer → Balance Designer → UX/UI Designer
```

Start with the Game Design Document, then iterate through each specialty as needed.
